Z3 commit message: nra: keep dyadic implied-bound artifacts out of the nlsat problem

Bounds derived by the eager bound squeeze return from the SMT layer as
asserted constraints whose rationals are LP-vertex/delta artifacts with
huge power-of-two denominators (e.g. 1367758954463/2^39). After
clearing denominators they inject outsized coefficients into the nlsat
polynomials and blow up resultant computations; on iss-8099 each such
run burned its entire 100K rlimit budget inconclusively, which the
cost-aware backoff then rightly punished, starving the search.

Skip constraints whose coefficients or right-hand side carry a
denominator divisible by 2^24 when building the nlsat problem. Genuine
decimal input constants (10^k = 2^k*5^k, small k) pass untouched.
Dropping constraints only weakens the problem, so infeasibility proofs
remain sound; if nlsat's model violates a skipped constraint the check
returns l_undef instead of asserting.

With this and the corrected cost measurement, iss-8099 solves in 1.8s
at every seed (pre-regression time was 1.9s), and iss-2603/iss-8208
remain repaired.

NFV Proof Coverage Map

A zoomable map of the Z3 src/ tree, mined from every NFV Formal Audit report published so far. Click a folder to zoom in, use the breadcrumb to zoom back out. Files are colored by the strongest proof evidence a Dafny audit ever produced for a property postulated on that file: green for a property Dafny proved, amber for an audited file where every attempt abstained, red for a property Dafny refuted. Hover a colored tile for the established properties. Click any file tile (not a folder) to request a new NFV audit of that file or one of its functions.

## Summary

Retain exact linear-relaxation upper bounds for real-valued nonlinear
objectives independently of whether the arithmetic hint is attainable.
This improves partial optimization answers under resource limits; it
does not claim additional solved benchmarks or a new complete nonlinear
optimizer.

- Add optional supporting-bound dependencies to
`lar_solver::maximize_term`, reusing the existing exact reduced-cost
dependency machinery.
- Add `theory_opt::maximize_with_bound` with a default implementation
that preserves existing backends. `theory_lra` supplies an optional
rational upper bound only after an optimal LP solve and a check of its
premises.
- Carry the bound in the per-call `opt_solver::maximize_result`,
separately from `bound_valid`, `hint`, and `hint_status`.
- Enable the path in geometric search for real objectives with
`opt.optsmt_dual_bounds=true` by default. Setting it to false disables
the new LP-certificate path, not existing refutation-based bounds.
- Preserve certified intervals through incomplete hint validation and
affected cancellation exits. An `unknown` trial is no longer treated as
proof that its threshold is an upper bound, and incomplete nlsat results
do not widen a tighter known upper bound.
- Extract the existing integer-column post-processing into
`adjust_integer_columns`, keeping its restoration, objective, and status
behavior unchanged.

## Soundness and scope

A finite LP optimum on one Boolean branch is not necessarily a global
upper bound. The new path checks the supporting dependencies:
definitions are unconditional, inequality sources contribute their
activating literals, and equality sources are expanded through the
existing congruence explanations. Every premise must be true at or below
the assertion base level. Untracked sources and premises depending on
deeper search decisions are rejected.

The certificate is established using exact rational simplex arithmetic;
a negative infinitesimal is conservatively dropped to obtain a closed
rational bound. This is an internal justification with tracked premises,
not a new exported proof format.

The feasible model remains separate from the upper endpoint. An
unresolved interval still returns `unknown`. Recognized
cancellation/resource exceptions from the affected nlsat fallback retain
the interval and an explicit unknown reason; unrelated exceptions are
rethrown.

This reuses existing simplex searches and NLA lemmas. It does not add a
second LP solve, new nonlinear cut generation, conditional-bound
aggregation across Boolean regions, or a generic driver.
